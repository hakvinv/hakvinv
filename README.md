## StudIPilot

**AI automation for German higher education.**

StudIPilot connects Stud.IP, course materials, university email, calendars, and tasks to AI assistants such as ChatGPT and Claude through a single MCP gateway. It synchronizes course files, makes them searchable, and links results back to their original pages.

- **Course materials:** automated retrieval and search with page references
- **University life:** access to email, calendars, and tasks
- **Access:** OAuth 2.0 with PKCE and separate permissions
- **Stack:** Python, FastMCP, SQLite, Railway, and hybrid search

The public code is a development snapshot and a starting point for self-hosting. Personal data and the private app connection are not included.

## SuperFlow ML

SuperFlow ML is a private research and development project for verifiable AI outputs. It checks proposed structures against defined rules and records decisions in traceable, hash-chained verification logs.

The code is private. One research application is [**T3 QGT on Zenodo**](https://doi.org/10.5281/zenodo.22975222), where the underlying structure was identified using SuperFlow. The report is available on request.
